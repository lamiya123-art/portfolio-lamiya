# Lamiya Shuaib P — Portfolio

A modern, interactive portfolio website showcasing frontend development and AI agent building expertise.

## Features

- **Custom Cursor Animation**: Smooth, animated cursor with hover effects
- **Gradient Backgrounds**: Dynamic background with grain texture for visual depth
- **Smooth Scrolling**: Fluid page navigation with easing animations
- **Reveal Animations**: Staggered entrance animations for content
- **Responsive Design**: Optimized for all device sizes with viewport meta tags
- **Modern Typography**: Custom fonts (Inter, JetBrains Mono) for clean readability
- **Dark Theme**: Carefully designed dark palette with purple/indigo accents

## Color Palette

- **Background**: `#050315` (deep dark)
- **Elevated Surfaces**: `#0c0930` (dark purple)
- **Primary Accent**: `#433bff` (indigo)
- **Text**: `#f4f3ff` (off-white)
- **Muted**: `#9a95c9` (soft purple)

## Layout

- **Max Width**: 1180px centered container
- **Grid Padding**: 32px horizontal margins
- **Radius**: 18px for rounded corners
- **Easing**: Custom cubic-bezier(`.16,.84,.44,1`) for smooth transitions

## Getting Started

1. Clone the repository
2. Open `index.html` in a modern web browser
3. No build process required - pure HTML/CSS

## Browser Support

- Chrome/Edge 90+
- Firefox 88+
- Safari 14+
- Requires support for:
  - CSS Grid & Flexbox
  - CSS Variables (Custom Properties)
  - CSS Backdrop Filter
  - Smooth Scroll Behavior

## Technology Stack

- **HTML5**: Semantic markup
- **CSS3**: Advanced styling with custom properties, backdrop filters, animations
- **Google Fonts**: Inter (body), JetBrains Mono (code)
- **Vanilla JavaScript**: Custom cursor, scroll animations, interactions

## Customization

### Changing Colors
Edit the CSS variables in the `:root` selector:

```css
:root {
  --bg: #050315;
  --indigo: #433bff;
  --text: #f4f3ff;
  /* ... more variables */
}
```

### Adjusting Animations
Modify the `--ease` variable for timing functions and transition delays in the `.reveal-stagger` classes.

### Responsive Breakpoints
Add media queries for tablet/mobile optimization as needed.
